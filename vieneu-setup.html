Cài đặt VieNeu-TTS Local

Giọng đọc AI tiếng Việt 48kHz miễn phí chạy trên máy tính của bạn — tương thích ngay với bản Chrome Web Store.

Không muốn cài đặt trên máy? Trong tab Nghe của Extension, bạn luôn có thể dùng "WebSocket TTS" hoặc "Web Speech API" miễn phí mà không cần cài thêm gì.

Yêu cầu hệ thống & Tổng quan

  • Hệ điều hành: Windows 10/11 (64-bit), macOS hoặc Linux. RAM tối thiểu 8 GB.
  • Dung lượng trống: ~4–5 GB. Lần chạy đầu tiên cần Internet để tự tải model AI (~1–2 GB), sau đó có thể chạy offline.
  • Tương thích Chrome Web Store: Extension giao tiếp qua cổng nội bộ 127.0.0.1:8000 nên dùng được ngay sau Cách 1 mà không cần Native Host.

2. Cài & chạy VieNeu trong 3 bước

Chọn tab đúng với máy của bạn rồi sao chép lần lượt 3 bước vào PowerShell (Windows) hoặc Terminal (macOS/Linux).

Chạy nhẹ trên mọi CPU hiện đại qua ONNX Runtime (không cần card rời, không cần PyTorch).

Bước 1: Cài công cụ nền (chỉ làm 1 lần)

Cài Git, uv (tự quản lý Python) và eSpeak NG (bắt buộc để phiên âm tiếng Việt). Nếu ngại cài bằng lệnh, bạn có thể bấm link bên dưới để tải trực tiếp eSpeak NG (.msi):

Tải eSpeak NG (.msi) Trang tải Git Mã nguồn VieNeu-TTS (GitHub) 
winget install --id Git.Git -e --source winget
winget install --id eSpeak-NG.eSpeak-NG -e --source winget
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Quan trọng: Sau khi cài xong Bước 1, hãy ĐÓNG cửa sổ PowerShell cũ và mở cửa sổ PowerShell MỚI để máy nhận lệnh git và uv.

Bước 2: Tải VieNeu-TTS và cài thư viện

Tải mã nguồn vào thư mục cá nhân và đồng bộ môi trường ảo (.venv):

git clone https://github.com/pnnbao97/VieNeu-TTS.git "$env:USERPROFILE\vieneu-tts"
cd "$env:USERPROFILE\vieneu-tts"
uv sync

Bước 3: Khởi động VieNeu Server

Mỗi lần muốn dùng giọng VieNeu (nếu không cài mục 3), chạy lệnh sau để bật server tại cổng 8000:

cd "$env:USERPROFILE\vieneu-tts"
uv run python -m apps.openai_speech

Lần chạy đầu tiên: Server sẽ tự tải model AI (~1–2 GB) từ Hugging Face nên có thể mất 1–5 phút. Hãy giữ nguyên cửa sổ Terminal đến khi thấy thông báo đang lắng nghe ở http://127.0.0.1:8000 (hoặc Uvicorn running), rồi bấm "Kiểm tra kết nối" ở đầu trang!

Tăng tốc CUDA cho card đồ họa NVIDIA (khuyên dùng VRAM ≥ 4 GB và driver NVIDIA mới).

3. Bật/Tắt Server 1-Click ngay trong Popup (Native Host)

Nếu không muốn mở Terminal mỗi lần nghe truyện, bạn có thể cài thêm gói Windows Companion để bấm nút "Bật Server" chạy ngầm ngay trong Popup (đồng thời tối ưu đa luồng cho AMD DirectML / CPU).

Extension ID hiện tại của bạn: 
...

Lưu ý: Extension ID khi cài từ Chrome Web Store sẽ khác bản Load Unpacked. Các lệnh bên dưới đã tự điền sẵn đúng ID hiện tại.

A. Tải gói Windows Companion

⬇ Tải STV-VieNeu Companion (Windows ZIP)

Tải và giải nén gói STV-VieNeu-Companion-Windows.zip từ trang Releases của extension (hoặc mở thư mục native-host nếu bạn cài bản unpacked).

B. Mở PowerShell trong thư mục vừa giải nén và chạy 1 lệnh

Nếu chưa cài VieNeu-TTS (tự cài công cụ + tải VieNeu + đăng ký nút Bật Server):

.\setup_vieneu.bat

Nếu bạn đã cài VieNeu-TTS ở mục 2 rồi (chỉ đăng ký nút Bật Server):

.\install_host.bat

Script sẽ lưu cấu hình vào %LOCALAPPDATA%\STV-VieNeu\host, sau khi cài xong bạn có thể xóa thư mục giải nén.

Bấm "Kiểm tra Native Host" để xác minh Chrome đã kết nối được với companion trên máy.

4. Câu hỏi thường gặp & Xử lý lỗi

Bấm "Bật Server" đợi lâu không lên hoặc báo quá thời gian?

Ở lần chạy đầu tiên, VieNeu-TTS cần tải bộ model AI (~1–2 GB) từ Hugging Face nên có thể mất vài phút tùy tốc độ mạng. Hãy chạy thử lệnh ở mục 2 một lần để thấy tải xong, từ các lần sau bật trong Popup chỉ mất vài giây.

PowerShell báo "uv is not recognized" hoặc "git is not recognized"?

Sau khi cài Git hoặc uv, Windows cần mở một cửa sổ PowerShell mới để nạp biến môi trường PATH. Hãy đóng cửa sổ cũ, mở PowerShell mới và chạy lại.

Gặp lỗi thiếu espeak / phonemizer khi tạo giọng đọc?

VieNeu-TTS bắt buộc dùng eSpeak NG để tách âm tiếng Việt. Hãy tải và cài file .msi của eSpeak NG (link ở Bước 1), sau đó khởi động lại Terminal và VieNeu Server.

Extension báo "Native host has exited" hoặc "forbidden"?

Lỗi "forbidden" xảy ra khi install_host.bat được chạy với Extension ID cũ (ví dụ đổi từ bản dev sang bản Chrome Web Store). Hãy copy lại Extension ID ở mục 3 và chạy lại install_host.bat.

Muốn đổi cổng (mặc định 8000) hoặc chuyển chế độ CPU/GPU?

Mở Popup Extension → tab "Cài đặt" → mục "Cấu hình TTS & Tự động chuyển chương" để sửa "VieNeu Server URL" hoặc "Chế độ chạy VieNeu", sau đó bấm "Lưu cấu hình".

Quick Novel Translator (STV) · VieNeu-TTS chạy cục bộ trên máy tính của bạn; dữ liệu giọng nói không bị gửi lên máy chủ ngoài.
